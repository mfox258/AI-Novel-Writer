# 文渊重构

2026-10-17：用户明确要求依据文渊构想直接重构现有软件。本目录记录本次迁移的当前映射，不改变旧版本规范与历史验收结果。

## 依据与解释

依据为用户提供的《文渊写作平台整体软件架构设计说明书 v1.0 · 审查修订01》及总纲0.12。旧v0.2包用于理解演进；与当前0.12不一致时不作为新实现依据。原机器合约仍为v0.5、1.0-proposed，不能将本文或本地ABI视为其正式发布。

本次授权允许直接进入渐进式实现；它不把原候选接口变成稳定协议，不证明未实现的权限、安装、持久化和兼容能力已通过验收。保留原软件作品格式、迁移注册表、项目会话隔离、定稿outbox和备份导出保护。

## 已有能力与迁移边界

| 文渊职责 | 现有实现 | 本次处理 |
|---|---|---|
| 公共契约 | `src/shared`中现有IPC及领域类型 | 新增`src/platform/contracts`的可信内置组件生命周期ABI，不替换现有业务载荷 |
| 内置扩展运行 | 先前由组件直接组合功能 | 新增`src/platform/plugin-runtime`：依赖、作用域、调用代次和失败回滚 |
| 工作台贡献 | 左栏及Sidebar硬编码小说视图 | `src/features/long-novel/public.ts`声明贡献；`src/bootstrap/workbench.ts`装配并绑定生命周期；宿主保留实际视图实现 |
| 应用服务 | `electron/services`及部分controller编排 | 继续复用已存在的项目授权、生成与定稿服务，尚未完成全部controller抽取 |
| 存储适配 | `electron/repositories`、`database.ts`、迁移注册表 | 沿用，未另建Artifact数据库或覆写项目格式 |
| 客户端 | `src/services/ipc-client.ts`及项目session | 手动正文客户端使用冻结session，禁止切换项目后落入另一作品 |
| 正文和版本 | `drafts/contents`、定稿收据、修稿合并 | 增加无模型/无蓝图的空白正文入口，修正历史发现与空正文恢复；逐次保存不可变修订尚待迁移 |
| 主题和组件 | 现有CSS Token及宿主React组件 | 保留现有主题；不把未批准的wy-ui Token或组件协议冒充已实现 |

工作台声明只包含已支持的视图键、图标和双语标签。插件不传React组件、函数、任意CSS或SQL；具体旧视图由宿主绑定。当前只支持可信内置声明，不支持安装用户脚本或第三方代码，运行时不是JavaScript安全沙箱。旧小说实现仍有直接IPC调用，尚未整体迁入受限plugin-sdk；本批不宣称全部源码边界已满足第24篇。

## 首批行为范围

1. 内置工作台激活后才公开导航；激活失败不留下部分贡献，停用移除贡献且不删除作者数据。
2. 保留AI章节入口，同时提供无需模型、蓝图或大纲的空白正文创建。
3. 版本历史应找到无蓝图草稿；空字符串是合法正文，恢复产生新草稿而不是覆盖原稿。
4. 前端品牌改为文渊；旧项目目录、配置键、应用数据标识、资源URI和安装包ID保持原值，避免误切数据位置。

## 仍需落实

2026-10-17续批已接通正文保存基线校验：IPC要求携带编辑器最后确认的`savedContent`，仓储在正文/元数据写事务内核对当前正文，不匹配返回`DRAFT_SAVE_CONFLICT`；编辑器保留本地内容、原基线和dirty状态，并提示手动合并。同一编辑器拒绝重叠提交，保存期间新增输入仍保持dirty，下次保存使用上次成功正文作基线。空字符串基线有效，缺少基线的IPC调用拒绝执行。可信主进程内部旧调用仍可省略基线，本批不是统一写入服务。

这是基于正文相等的冲突保护，不是持久expected-head：正文先改变又恢复到原值的ABA变化不能识别。没有新增历史表或持久operationId，通信结果丢失后的自动重放、不可变修订和历史恢复仍按下述迁移闭包继续实施。

- **正文持久修订：** `DraftRepository.updateContent`仍沿用旧可编辑内容语义。需要追加修订、expected-head并发检查、持久operationId结果和统一写入服务；不能把`drafts.version`直接改成每次保存次数。
- **迁移及完整导出：** 修订表落地前须同步物理schema注册、旧正文初始版本映射、可移植字段政策、恢复与清理引用闭包，历史覆盖过的内容无法凭空补回。
- **扩展可信绑定与权限：** 内置ABI不替代0.11/0.12的来源、包、安装、授予和撤销协议。模型调用与外发仍须分开治理。
- **领域版本与分支：** 当前章节/草稿不等于完整Document/Revision、WorkingSet和CanonSnapshot模型；不新增不受控Artifact JSON袋。
- **多种创作入口：** 手动入口先落地；完整聊天提案/表单对同一版本模型的汇流尚未完成。
- **其余领域：** 人物知识/信念、POV、通用字段登记、词条、叙事承诺、上下文三环和外部Markdown冲突协议仍按依赖推进，不能靠重命名宣称完成。

验证命令与本次实际结果记录在[验证记录](verification.md)。源码测试、浏览器交互与安装包运行是不同证据；未运行的项目明确保留为未验证。
